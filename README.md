# SeeU
<a href="https://seeu.ae"><strong>View Live Demo »</strong></a>

## About the Project
SeeU is a social platform website for tourists and locals to discover new people and friends,
have meetups with them in the most known and touristic locations in Dubai.


## Features
- Live feed with users
- Pass or 'Let's meet!'
- Live messaging
- User Profile
- OAuth Authentication
